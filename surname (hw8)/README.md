# Homework 8

Python project with separate modules for calculations and formatting.

## Structure

```text
study_tools/
├── __init__.py
├── calculations.py
└── formatting.py
demo.py
```

## Virtual environment

Create:

```bash
python -m venv .venv
```

Activate on Windows:

```bash
.venv\Scripts\activate
```

Run:

```bash
python demo.py
```

Deactivate:

```bash
deactivate
```

No external packages are required.
